## 📌 Project Overview

**Memory Match Mania** is an interactive Java desktop game developed as a capstone project for **CSA0926 – Programming in Java**.

The application combines a traditional **memory card matching game** with an interactive **scenario-based decision game**. Players can select themes and difficulty levels, match cards, answer scenario-based questions, track their performance, and view their game history and leaderboard rankings.

The project demonstrates practical implementation of important Java programming concepts including:

- Object-Oriented Programming
- Collections Framework
- Exception Handling
- Multithreading
- Java Swing
- Event-Driven Programming
- Game Logic
- Score and Timer Management
- Data Management

# 🎯 Objectives

The main objectives of Memory Match Mania are:

- To develop an interactive Java-based desktop game.
- To implement memory-based card matching mechanics.
- To introduce scenario-based decision-making gameplay.
- To demonstrate Object-Oriented Programming principles.
- To use Java Collections for card and game-data management.
- To implement input validation and exception handling.
- To use multithreading for background timer operations.
- To develop an interactive graphical interface using Java Swing.
- To track player score, moves, and completion time.
- To maintain player game records and performance statistics.

# 🎮 GAME MODES

## 🃏 1. Matching Cards

Matching Cards is the classic memory game mode.

### How to Play

1. Register as a player.
2. Select **Matching Cards**.
3. Choose a theme.
4. Select a difficulty level.
5. Flip cards to reveal their images.
6. Remember the positions of the cards.
7. Find identical pairs.
8. Matched pairs remain visible.
9. Continue until all pairs are matched.
10. View the final score, moves, time, and result.

### Difficulty Levels

| Level | Difficulty | Grid Size | Cards | Pairs |
|---|---|---:|---:|---:|
| Level 1 | Easy | 4 × 4 | 16 | 8 |
| Level 2 | Medium | 5 × 5 | 25 | 12 + Bonus |
| Level 3 | Hard | 6 × 6 | 36 | 18 |

As the difficulty increases, the number of cards and matching pairs increases.

# 🎯 2. Scenario Match

Scenario Match extends the memory-game concept with **scenario-based decision making**.

Players are presented with scenario questions and select an appropriate answer through an interactive card-based interface.

### Gameplay Includes

- Scenario questions
- Answer selection
- Question progress
- Score tracking
- Move tracking
- Timer
- Difficulty levels
- Completion result

```text

      ↓

      ↓
Select an Answer
      ↓

      ↓

      ↓
Next Question
      ↓
Complete Scenario Level
